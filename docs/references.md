# References

## Core Papers And Code

- Trabelsi et al., *Deep Complex Networks* (ICLR 2018).
- Reference implementation:
  [ChihebTrabelsi/deep_complex_networks](https://github.com/ChihebTrabelsi/deep_complex_networks).
  The repository contains code for the experiments from the paper, including
  computer vision and MusicNet workflows.
- Hirose, *Complex-Valued Neural Networks* (Springer).
- Arjovsky et al., *Unitary Evolution Recurrent Neural Networks*.
- Virtue et al., *Complex-Valued CNNs for MRI Fingerprinting*.

## Project Notes

This repo is PyTorch-first and evidence-first. Older reference implementations
are useful for architecture, initialization, and benchmark design, but the
experiments here should use the local `uv` environment, result manifests, and
baseline rules documented in this repository.
